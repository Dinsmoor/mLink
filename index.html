mLink

Documentation

mLink is a complete radio messaging system for organised communications: an HF data network, a mail system and a net-control tool in one package. It turns an SSB transceiver, a sound interface and a computer into a capable messaging platform for emergency and recreational use.

This repository holds the current quickstart and full system manual for mLink. It is considered a work in progress until stated otherwise.

There are two documents for mLink you may be interested in:

  • Quickstart A brief introduction to the mLink system. Start here if you're new to mLink.
  • mLink Manual Complete system documentation. Comprehensive reference for all mLink features and functionality.
